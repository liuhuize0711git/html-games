# 尖塔行者 · 网页版（Spire Wanderer Web）

《尖塔行者》的浏览器版本：**一个 `index.html` 单文件**，双击就能玩，也可以直接丢到任何静态托管上联网玩。
规则、卡牌、敌人、遗物、商店与事件都和 C 版保持一致。

---

## 1. 怎么玩

**方式 A：直接打开**

双击 `index.html`（或拖进浏览器）即可开始。无需服务器、无需联网、没有任何外部依赖。

> 用 `file://` 直接打开时，部分浏览器会禁用本地存储，此时「自动存档」会失效，其它功能不受影响。

**方式 B：本地起个静态服务器**

在 `index.html` 所在目录执行任意一种：

```bat
:: Python
python -m http.server 8123

:: Node.js
npx serve .
```

然后浏览器打开 `http://127.0.0.1:8123/`。

**方式 C：放到网上（推荐，随时随地都能玩）**

`index.html` 是纯静态单文件，任何静态托管都能用，例如：

* **GitHub Pages**：新建仓库 → 上传 `index.html` → Settings → Pages → Source 选 `main` 分支根目录 → 访问 `https://<用户名>.github.io/<仓库名>/`
* **Netlify / Vercel / Cloudflare Pages**：把 `index.html` 拖进它们的「拖拽部署」页面即可拿到网址
* **自己的服务器 / 对象存储**：上传后直接用浏览器访问该文件

手机浏览器同样可以玩（界面自适应，手牌横向滑动）。

## 2. 玩法速览

* **目标**：从第 1 层爬到第 15 层，击败塔顶首领。
* **战斗**：每回合 3 点能量，点击手牌打出；需要指定目标的牌会先让你点敌人。
* **格挡**在你的回合开始时清零；**易伤**（受到攻击 +50%）、**虚弱**（造成攻击 -25%）、
  **无力**（获得格挡 -25%）、**中毒**、**力量 / 敏捷 / 荆棘 / 镀甲 / 恶兆** 都显示在角色下方。
* **敌人意图**显示它下回合要做什么，据此决定格挡还是猛攻。
* **成长**：战斗胜利三选一拿牌；营火可以回复、升级或移除卡牌；商店可买牌、药水、遗物，也能删牌。
* **存档**：自动保存在浏览器 `localStorage`，主菜单可以「继续上次的冒险」；通关或阵亡后清除。

### 5 个角色

| 角色 | 生命 | 初始遗物 | 特点 |
| --- | --- | --- | --- |
| 铁卫 | 78 | 燃烧之血 | 力量与格挡，硬扛 |
| 影袭 | 68 | 蛇之戒指 | 中毒与抽牌，快攻匕首 |
| **故障机器人** | 72 | **闪电核心**（战斗开始时生成 1 个闪电充能球） | 充能球：闪电 / 冰霜 / 黑暗 |
| **储君** | 70 | 光滑石头 | 星费 + 铸造（牌组里自带一把**君王之剑**） |
| **缚亡者** | 66 | 战术手册 | 召唤**大脚**与恶兆 |

### 新机制的动画

* **充能球**：人物上方一排球槽，**新球从最右边往左边填**；凝聚时球会弹出来，激发时球会飞向目标后消失，
  回合结束的被动会让球脉冲一下。球槽满了会把最旧的球挤掉。
* **随从「大脚」**：站在人物**右边**。召唤时从地上蹦出来（弹出 + 放大动画），
  替你踩敌人时整只脚抬起砸下并带冲击波，吃到伤害时会闪红并抖动。
* **君王之剑**：铸造时人物头顶的「君王剑：N」会放大发光；挥剑时敌人身上会有金色斩击轨迹。
* 其它：星费、恶兆、镀甲、临时效果都有对应的飘字提示。

操作：

| 操作 | 方式 |
| --- | --- |
| 出牌 | 点击手牌（或按数字键 `1`–`9`） |
| 选目标 | 目标高亮时点击敌人 |
| 结束回合 | 右下角「结束回合」按钮或 `E` / 空格 |
| 查看牌堆 | 「牌堆」按钮或 `D` |

| 切换动画速度 | 「动画：正常 / 快 / 关闭」按钮 |
| 查看全部可用卡牌 | 主菜单 →「卡牌一览」 |

## 3. 关于卡牌效果（重要）

奖励 / 商店 / 事件里**只会出现本作完整实作了效果的卡牌**：

* 导入的《杀戮尖塔 2》卡牌共 **597 张**，其中 **260 张**完整可用，会进入奖励池；
* 其余的牌描述里带有本作没有实作的机制，**不会出现在任何获得卡牌的途径里**：
  * 37 张多人合作限定牌（本作是单机）
  * 93 张带「每当…… / 如果…… / 若……则……」的**条件与触发**牌 —— 本作没有条件判定与事件触发系统，
    解析器只能把数值当成无条件生效（例如「如果本回合没打出过攻击牌，则抽 2 张」会变成无条件抽 2 张）
  * 239 张含有无法解析的复杂效果（动态费用、特殊目标选择、本作没有的状态等）
  * 62 张诅咒 / 状态 / 衍生 / 事件牌（本来就不作为奖励）
* 加上本作自带的 41 张基础牌，实际能拿到的牌共 **280 张**。

也就是说：**你抽到 / 买到的每一张牌，描述里写的效果都能真的用出来。**

## 4. 和 C 版的关系

* 同一套数据：卡牌（含简体中文描述）、14 种敌人（含 3 精英 + 2 首领）、9 件遗物、7 种药水、6 个随机事件、15 层地图。
* 同一套数值与判定：能量、抽牌、格挡、易伤（+50%）、虚弱（-25%）、中毒、荆棘、洗牌、敌人 AI、奖励稀有度权重。
* 新机制实现一致：充能球（从右往左填）、随从、铸造 / 君王之剑、星费、恶兆、镀甲、「下回合回手」、关键字（消耗 / 虚无 / 固有 / 保留 / 奇巧 / 永恒 / 无法打出）。
* C 版是终端里的字符画界面；网页版是 SVG 小人 + CSS 动画，鼠标点击操作，带血条、能量球、意图与消息面板。

## 5. 说明

* 单文件内部分成两段脚本：`ENGINE`（纯逻辑，不碰 DOM）与界面层。引擎段落可以单独抽出来在 Node 里跑自动化测试。
* 浏览器控制台里有个调试入口：`window.__spire.engine`（查看当前状态）、`window.__spire.render()`（重绘界面）。
* 想改数值：直接编辑 `index.html` 里的 `CARDS` / `ENEMIES` / `RELICS` / `POTIONS` / `EVENTS` 数组即可。
* 本作为个人娱乐用途的原创实现，未使用任何第三方素材。
